# 博客项目系统性优化计划

## 📊 优先级评估标准
- **业务价值**: 对用户体验、SEO、可访问性的影响程度
- **技术风险**: 实施难度、可能引入的bug风险
- **投入产出比**: 工作量与收益的比例

---

## Phase 1: 基础修复 (高优先级 + 低风险)

### 1.1 语言与版权修复
- 将所有页面 `lang="en"` 改为 `lang="zh-CN"`
- 修复 `site.ts` 中的版权信息 `© 2025 Someone` → `© 2025 Junlin`

### 1.2 导航清理
- 移除 Navigation.astro 中无效的 Comments 导航链接

### 1.3 SEO 优化
- 添加完整的 meta description 和 keywords
- 添加 Open Graph 标签（社交分享预览）
- 添加 Twitter Card 标签
- 添加 canonical URL

### 1.4 代码语法高亮
- 集成 Shiki 代码高亮器
- 配置主题和语言支持

---

## Phase 2: 用户体验增强 (中优先级 + 中风险)

### 2.1 移动端导航
- 添加汉堡菜单组件
- 实现响应式导航抽屉
- 添加过渡动画

### 2.2 暗黑模式
- 创建主题切换组件
- 添加 CSS 变量支持
- 实现主题持久化 (localStorage)

### 2.3 返回顶部按钮
- 创建 BackToTop 组件
- 添加滚动显示/隐藏逻辑
- 平滑滚动动画

### 2.4 图片优化
- 使用 Astro Image 组件
- 添加 lazy loading
- 配置 WebP 转换

---

## Phase 3: 功能完善 (低优先级 + 低风险)

### 3.1 RSS 订阅
- 集成 `@astrojs/rss`
- 创建 RSS feed 页面

### 3.2 View Transitions
- 添加 `@astrojs/view-transitions`
- 配置页面切换动画

### 3.3 Sitemap
- 集成 `@astrojs/sitemap`
- 配置自动生成
